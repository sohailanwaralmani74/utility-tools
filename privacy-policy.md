  <h2>1. How IamRango Works</h2>
  <p>
    All tools on IamRango are designed to operate entirely within your web browser. This means:
  </p>
  <ul>

    <li><strong>Local processing only:</strong> All actions (like converting, editing, or analyzing files) are handled securely in your own browser using technologies such as JavaScript and WebAssembly (e.g., FFmpeg-wasm).</li>
    <li><strong>No data storage:</strong> Once you close or refresh the page, any temporary data in memory is permanently cleared.</li>
  </ul>
  <p>

  </p>
